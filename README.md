# Manga API Webscraper

This project is a web scraper for fetching manga details, chapter lists, and images from different manga sites using a REST API built with Express and TypeScript.

## Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

## Setup

1. **Clone the repository:**

   ```sh
   git clone https://github.com/JunSayke/manga-api-webscraper.git
   cd manga-api-webscraper
   ```

2. **Install dependencies**

   ```sh
   npm install
   ```

3. **Compile the TypeScript code**

   ```sh
   npm run build
   ```

4. **Run the server**
   ```sh
   npm start
   ```

## Contribution Guidelines

To contribute to this project, follow these steps:

1. Fork the repository:

   Click the "Fork" button at the top right corner of the repository page on GitHub.

2. Clone your forked repository:

   ```sh
   git clone https://github.com/JunSayke/manga-api-webscraper.git
   cd manga-api-webscraper
   ```

3. Create a new branch:

   ```sh
   git checkout -b feature/new-manga-site
   ```

4. Implement your changes:

   - Adding new serivce:
     Create a new service class in the services directory by extending the AbstractMangaService class.
     Implement the required methods. Refactor serviceFactory.ts accordingly.

   - Improving README.md:
     Help me

   - Open for improvements:
     ```sh
        cd utils
     ```

5. Push your changes to your forked repository:

   ```sh
   git push origin feature/new-manga-site
   ```

6. Create a pull request:

   Go to the original repository on GitHub and click the "New pull request" button. Select your branch and submit the pull request for review.
